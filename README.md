# 参加率アプリ（画面がわ）

協議会が「この業者を会員に召集するか」を判断するための、事実データを溜めるアプリ。
このフォルダは **画面（入力ボタン）だけ** を持っている。
データの受け皿（スプレッドシート・GAS・集計・召集判定）はコワークがわの担当。

- 設計書：`01 設計書 SOW.pdf`
- GASの窓口：`assets/api.js` の `GAS_URL`

## ファイルの役割

| ファイル | なにをするか |
|---|---|
| `index.html` | 参加者アプリ（業者が使う）。企画をえらんで送るだけ |
| `assets/sanka.js` | 参加者アプリの動き |
| `assets/api.js` | **GASとのやりとりは全部ここ**。項目名を直すのもここだけ |
| `assets/style.css` | 見た目。スマホ縦画面が前提 |
| `vercel.json` | バーセルの設定（`/member` でメンバー画面を開けるようにする） |
| `member.html` | メンバーアプリ（協議会メンバーが使う）。`/member` で開く |
| `assets/member.js` | メンバーアプリの動き |

## ビルドは要らない

素のHTML・CSS・JSだけ。npm も Node も要らない。
ファイルを GitHub に置けば、バーセルがそのまま公開してくれる。

## のこりの作業

### 1. 業者マスターの「よみ」が空（コワークがわ）

列ずれは GAS v1.3 で直った（執行部Aが `judge:"対象外"` に戻ったのを確認ずみ）。
ただし **よみ列の中身がまだ空**なので、漢字ではじまる事業所は
50音の「その他」に入る。埋まれば画面は無修正で正しく並ぶ。

画面がわには「ひらがな・カタカナ以外の `yomi` は無視する」
（`api.js` の `cleanYomi`）という番人が入れてある。
列がまたずれても、50音の並びが巻きぞえで壊れることはない。

### 1-2. GASのメニューに危ないものが2つある（運用前に外すこと）

- `clearTestData()` … 「テストデータを消す」という名前だが、
  参加記録・報告・経費・推薦を **2行目以降まるごと削除する**。テストかどうかを見ていない
- `insertTestData()` … リーダーマスターを条件なしで上書きする

どちらも `onOpen()` のメニューから外してもらう。依頼文は `docs/cowork-request.md`。

### 2. テストデータを消すこと

通しの確認のために入れたもの。運用の前に消す。

- プロジェクトマスター … `P001【テスト】動作確認`
- 参加記録シート … 陽気の1行
- メンバー報告シート … 経費2件（駐車場代1,200／弁当4,500）と良かった業者1者ぶん

## 動作確認ずみのこと

通しで動く。以下は実際に叩いて確かめた。

**参加者アプリ**
- masters を読んで業者ボタン・企画ボタンを自動で作る（ベタ書きなし）
- 事業所は初回に1回えらべば端末が覚える（次からは企画を押して送るだけ）
- 覚えたIDがマスターから消えていたら、黙って進めず選択画面に戻す
- 送信 → シート1に1行入った（`summary` の `join` が 0→1）
- もう一度送ると `duplicated: true` → 「すでに記録ずみです」画面。**行は増えない**
- 存在しない企画IDを送ると、GASの日本語メッセージがそのまま画面に出る

**メンバーアプリ**
- 種別をえらぶとリーダーが自動で出る
- その種別の企画だけが出る
- 企画をえらぶと `participants` を引いて、**その企画に参加した業者だけ**がボタンになる
- 経費は何行でも足せる。「1,200」「1200円」どちらで打っても数字として読む
- 送信 → シート2に入り、`summary` に反映（`rec` 0→1、`cost` 5,700、
  名目別集計に「駐車場代」「弁当」が出た）

### 「推薦ずみ」を最初から選んだ状態にしていない理由

`participants` は `推薦ずみ` を返してくれるが、**目じるしのバッジを出すだけ**にしてある。
報告は出すたびに1件積まれるので、最初から選んだ状態にすると、
報告を出しなおすたびに推薦回数が水増しされてしまう。
推薦回数は召集判定の軸そのものなので、ここは手で選んでもらう。

## バーセルに公開する手順

1. GitHub で新しいリポジトリを作る（Face ID でログイン）
2. このフォルダの中身をアップロードする
3. バーセルで「Continue with GitHub」→ そのリポジトリを Import
4. 設定はさわらず Deploy（ビルド設定は空のままでいい）
5. 出てきた URL が参加者アプリ。メンバーアプリは その URL のうしろに `/member`

参加者にはトップの URL だけを配る。`/member` は協議会メンバーにだけ教える。

## スマホまわりで気をつけたこと（消さないでほしい指定）

- 入力欄の文字は 16px 未満にしない … 小さくすると iPhone が勝手に画面を拡大する
- `100vh` を使わない（`100svh` を使う） … キーボードが出たとき画面が飛ぶ
- 押せる部分は 56px 以上 … 誤タップ防止
- `overscroll-behavior: contain` … スクロールが親に伝わって暴れるのを防ぐ
